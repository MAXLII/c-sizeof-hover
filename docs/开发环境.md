# 开发环境

## 所需软件

| 软件 | 版本 | 说明 |
|------|------|------|
| VS Code | ≥ 1.85.0 | 扩展开发与调试 |
| Node.js | ≥ 18 LTS | 运行时（推荐 22 LTS） |
| npm | ≥ 10 | 随 Node.js 安装 |

## 工具链

项目使用以下工具（通过 `npm install` 自动安装）：

| 工具 | 用途 |
|------|------|
| TypeScript 5.x | 源码编译 |
| webpack 5.x | 打包输出单文件 |
| ts-loader | webpack 的 TypeScript 加载器 |
| @vscode/vsce | 打包 VSIX |

## 环境配置步骤

### 1. 安装 Node.js

从 [nodejs.org](https://nodejs.org) 下载 LTS 版本并安装。

验证安装：

```bash
node --version   # ≥ v18.0.0
npm --version    # ≥ 10.0.0
```

### 2. 克隆仓库

```bash
git clone <repo-url>
cd vsix_dev
```

### 3. 安装依赖

```bash
npm install
```

### 4. 编译

```bash
npm run compile      # 开发模式，输出到 out/extension.js
```

或监听模式（保存自动编译）：

```bash
npm run watch
```

### 5. 调试

在 VS Code 中打开项目根目录，按 `F5` 启动 Extension Development Host。

项目 `.vscode/launch.json` 已预置调试配置：
- 按 `F5` 自动执行 `compile` 任务并启动扩展
- 在 Extension Development Host 中打开 C 文件即可测试

### 6. 打包 VSIX

```bash
npm run package      # 执行生产编译并打包为 .vsix
```

## 无头编译（仅命令行）

如果不需要 VS Code 调试，仅编译和打包：

```bash
npm install
npm run compile
npx @vscode/vsce package
```

## 工程结构

```
vsix_dev/
├── src/                  # TypeScript 源码
│   ├── extension.ts      # 入口
│   ├── hover-provider.ts # HoverProvider 实现
│   ├── config.ts         # 配置读取
│   ├── logger.ts         # 日志模块
│   ├── parser/           # C 类型解析器
│   │   ├── c-type-parser.ts
│   │   ├── document-cache.ts
│   │   └── parser-manager.ts
│   └── type-system/      # 类型系统与 sizeof 计算
│       ├── types.ts
│       ├── primitive-sizes.ts
│       ├── size-calculator.ts
│       └── type-resolver.ts
├── test-data/            # 测试用 C 文件
├── out/                  # 编译输出（gitignore）
├── package.json          # 扩展清单与脚本
├── tsconfig.json         # TypeScript 配置
├── webpack.config.js     # webpack 配置
└── .vscode/              # 调试与任务配置
```
